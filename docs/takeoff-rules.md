# 산출 기준과 근거

## 상태

실제 업무 기준은 미확정이다. `rules/planar-v1.json`은 첫 엔진의 명시적인 수학적 처리 방식이며 교육청/기관의 승인된 적산 기준이 아니다. 예시 소수 3자리·사사오입은 합성 테스트 설정이다. 웹은 사용자가 단위·반올림·근거를 선택해야 요청을 받는다.

## 길이와 단위

지원 객체의 모델 공간 XY 중심선 길이를 계산한다. LINE은 `sqrt(dx²+dy²)`, 직선 폴리선은 구간 길이 합이다. 높이가 변하는 LINE/3D POLYLINE은 평면 길이로 조용히 투영하지 않고 미지원으로 남긴다. 기울어진 OCS도 미지원이다. 일정 Z의 수평 평면 객체는 처리하지만 그 Z를 실제 층 높이라고 해석하지 않는다.

폴리선 곡선은 bulge(곡선 부풀음)를 사용한다. 현 길이 c, bulge b에 대해:

```text
theta = 4 × atan(abs(b))
radius = c × (1 + b²) / (4 × abs(b))
arc_length = radius × theta
```

닫힌 폴리선은 마지막→첫 점 구간까지 포함한다. 일반 2D POLYLINE도 bulge를 처리하지만 곡선 맞춤/스플라인 맞춤·메시·폴리페이스는 제외한다. 폭은 중심선 길이를 바꾸지 않으며 실제 관경은 사용자 지정 값이다.

`$INSUNITS`는 참고만 제공한다. m 변환 계수는 사용자 확인 단위 mm=0.001, cm=0.01, m=1이다. 출력 축척·DIMSCALE을 길이에 곱하지 않는다. 알려진 실제 치수로 단위를 확인할 책임과 근거를 기록한다. 나머지 단위는 첫 버전 미지원이다.

## 대상과 중복

객체 하나는 단일 관경 구간이다. 도중에 관경이 변하면 AutoCAD에서 분할하고 새 버전으로 등록한다. 원본을 웹에서 자동 분할하지 않는다. 원본 도면층·색상은 의미 판정 규칙이 아니다.

확정된 급수 객체만 계산하며, 완전히 같은 구간 모음의 중복(반대 방향 포함)은 사용자가 하나를 확정하고 나머지를 명시적으로 제외해야 계산한다. 미검토 중복이 있거나 둘 다 확정이면 해당 객체들을 계산 보류한다. 허용오차 기반 근접 중복·부분 겹침·서로 다른 분할 방식·끊긴 선은 자동 정리하지 않는다. 연결과 평면 교차도 판정하지 않는다. 도면 검토 때 별도로 확인해야 한다.

TEXT/MTEXT는 문자와 위치만 제공한다. INSERT는 블록 이름·삽입점·회전·축척·속성·자식 종류/수·외부참조 여부를 기록하며 내부 길이는 계산하지 않는다. XREF를 외부 경로에서 읽지 않는다. CIRCLE, ARC, SPLINE, HATCH, 치수선, 프록시/특수 객체 등은 미지원으로 남긴다. 배치 공간은 제외 개수를 기록한다.

## 집계·반올림·기준 버전

모델 길이는 float의 기하 계산 결과를 십진 문자열로 저장하고, 변환·합산·최종 반올림은 Python Decimal로 수행한다. 동일 엔진/의존성·파일·확인 정보·기준에서 계산 JSON은 동일하다. DXF/XLSX 파일 바이트는 생성 시각 등 메타데이터 때문에 달라질 수 있다.

객체 길이를 각각 반올림하여 합치지 않는다. 관경별 원시 길이 합계에 대해 지정한 소수 0~6자리와 사사오입/짝수 반올림/버림을 적용한다. 객체 행에는 반올림 전 길이를 보존한다. `version` 외에 기준 JSON 해시도 저장하므로 같은 기준 이름에서 설정을 바꾸어도 구별된다.

부속 공제·가산, 할증, 보온, 입상, 기구 연결 길이는 적용하지 않는다. 계산 0으로 확인한 것이 아니라 첫 범위에서 미산출이다. 근거 없이 비율이나 기구별 기본 길이를 넣지 않는다. 해당 필드를 다른 값으로 바꾸면 엔진이 지원하지 않는 설정으로 거부한다.

## 표준 CAD와 엑셀

확정 객체만 별도 DXF의 `STD_WATER_DN{관경}` 도면층으로 옮기고 색상 5(표시 예시)·Continuous/BYLAYER를 적용한다. 기존에 같은 이름이 있으면 다른 이름을 만들어 원본 작성자의 레이어 설정을 보존한다. 객체의 직접 true color는 출력 복사본에서 제거하여 BYLAYER 표시를 적용한다. XDATA에 파일 해시·원본 handle·기준을 기록한다.

이는 표준 표시 **예시**이며 실무 CAD 표시 표준의 최종 승인이 아니다. 관경·근거 등의 공통 데이터는 JSON/XLSX에 보존한다. 표준 레이어 적용만으로 정보 표준화 완료를 주장하지 않는다. ezdxf 재저장이 AutoCAD 특수 객체·모든 시각 속성의 무손실 왕복을 보장하지 않으므로 실제 CAD 열기 비교가 필요하다.

엑셀의 계산식은 추적용 텍스트다. 사용자 문자열을 수식으로 실행하지 않는다. 객체 단위 값은 정밀도 보존용 문자열이며 MQC 품목 코드/입력 양식으로 승인되지 않았다. MQC와 이 엔진 양쪽에서 할증 등을 중복 적용하지 않도록 후속 매핑 단계에서 확인한다.
